# 0003. 동적 품질 프로필과 이중 인계 수락

- 상태: `accepted`

## 맥락

결함이 하나라도 있으면 실패시키는 방식은 품질 보증이 아니라 무결점 요구가 된다. 반대로 모든 품질을 평균 점수로 합치면 보안이나 자료 무결성 실패를 문서 품질로 상쇄할 수 있다. 또한 보내는 전문가의 자기 보고만으로 인계를 끝내면 다음 전문가가 자료를 처음부터 다시 만들어야 할 수 있다.

## 결정

세 책임 축은 요구 작성 단계에서 과업 목적에 맞는 동적 품질 프로필을 공동 작성한다.

정확성·보안·자료 무결성·필수 기능과 과업별 핵심 품질은 항목별 비보상 하한으로 둔다. 하나라도 하한에 미달하면 다른 장점으로 상쇄하지 않는다. 모든 필수 하한을 넘긴 뒤 사용성·유지보수성·성능 여유·문서성·운영 편의성 같은 개선 품질을 원하는 결과 기여도로 종합 평가한다.

품질 수준은 과업 목적에 따라 달라진다.

- 시제품: 지정 조건의 핵심 동작과 한계 전달
- 일반 프로그램: 정상·경계·일반 오류와 유지 가능한 품질
- 보안 프로그램: 일반 품질에 악의적 입력·우회·부정 시험을 추가
- 연구 프로그램: 일반 품질에 방법 타당성·의미 일치·평가지표·실험 무결성·재현 계보를 추가

모든 전문가 인계는 두 단계로 수락한다.

1. 정책 엔진의 형식·계보·파일·SHA-256·권한 자동 검사
2. 수신 전문가의 “처음부터 다시 만들지 않고 이어서 일할 수 있는가” 확인

인계 수락은 최종 품질 통과가 아니다. 검증·품질 보증 책임 축이 품질 프로필에 따라 별도로 판정한다.

## 결과

### 장점

- 원하는 결과에 충분히 기여하는지를 기준으로 품질을 판정한다.
- 핵심 품질 실패가 평균 점수에 가려지지 않는다.
- 낮은 영향의 결함이 있어도 필수 품질을 충족하면 통과할 수 있다.
- 다음 단계에서 대규모 재작업이 필요한 부실 인계를 조기에 차단한다.

### 비용

- 요구 단계에 품질 프로필과 측정 방법 작성이 추가된다.
- 수신 전문가의 인계 확인이 필요하다.
- 근거 없는 수신 거부를 다시 검사해야 한다.

## 기각한 대안

### 모든 결함이 자동 실패

원하는 결과 기여와 품질 수준을 고려하지 않아 기각했다.

### 모든 품질의 가중 평균

필수 보안·정확성 실패를 다른 품질로 상쇄할 수 있어 기각했다.

### 자동 해시 검사만으로 인계 수락

형식은 맞지만 다음 작업에 쓸 수 없는 자료를 통과시킬 수 있어 기각했다.

### 모든 인계를 품질 보증 책임 축이 승인

일상 인계가 병목이 되므로 자동 검사와 수신자 확인으로 분리했다.

## 확인 방법

- 세 책임 축의 기여 없이 품질 기준선을 확정하면 거부된다.
- 필수 품질 하한 하나를 개선 품질 점수로 상쇄하면 거부된다.
- 산출물·해시 자동 검사나 수신 확인 중 하나가 실패하면 다음 작업을 시작할 수 없다.
- 수신 거부에는 부족한 품질 항목·필요 자료·재작업 범위가 있어야 한다.
