# Agent Workflow Harness

사용자 목표를 점검해 탐색·제작 경로와 단계별 전문 역할을 구성하고, 역할별 작업 공간·정형 인계·불변 후보본·추가 전용 증거 기록·단계 통과 규칙으로 다중 에이전트 개발을 통제하는 Hermes 플러그인입니다. 결정론적 상태·권한·해시·증거 관리는 Python 핵심 엔진이 맡습니다.

## 구현된 기능

- 목표 충분성 점검과 탐색·제작 경로 분기
- 위험·연구 산출물 여부에 따른 역할 동적 구성
- 미션·revision·작업·시도·작업자·작업 공간·후보본에 결속된 일회성 권한 증표
- 중앙 정책 검사와 추가 전용 사건 기록에 따른 상태 변경·재생·변조 탐지
- 체크포인트·중단·새 시도 재실행과 중복 명령 멱등 처리
- `mission_id`·revision 기반 현재 과업 보호와 다른 과업에서 온 비동기 결과 격리
- 역할별 쓰기 경로·명령·승인 권한
- JSON Schema, 실제 산출물 SHA-256, 독립 소유 기대 결과·판정 규칙·관찰·주장을 함께 검사하는 인계
- 단계별 필수 입력의 출처·종류·SHA-256과 실제 출력 종류를 연결하는 완료 판정
- 불변 후보본과 부모·자식 계보, 후보본 manifest 해시의 정책 사건 결속
- 후보본·인계·증거 경로의 심볼릭 링크 거부와 동결 뒤 변조 탐지
- SQLite 추가 전용 증거 기록과 해시 사슬, 다른 미션·revision·후보본으로의 증거 파일 재결속 차단
- 오래된 증거·자가 승인·상태 건너뛰기 차단
- 출시·제한적 출시·보류·출시 금지 판정과 승인된 후보본의 결정론적 출시 묶음
- Hermes CLI 실행기와 시험용 기록 실행기
- Hermes 플러그인 도구·`/workflow` 명령·내장 스킬
- 미션 JSON 저장과 Hermes 재시작 뒤 상태 복원

## 검증 범위

현재 구현은 단위·통합 시험, Ruff, mypy로 검사하고 있습니다. 권한 사칭, 다른 작업 공간·시도에서 훔친 권한 증표 재사용, 빈 산출물·허위 완료, 후보본·manifest·증거 변조의 주요 차단 경로를 자동 시험으로 확인합니다.

남은 검증은 중단 시점별 복구, 외부 작업 성공 뒤 응답 유실, 중복 외부 효과, 검증 실행기 오류, 오래된 revision 증거를 묶은 종합 결함 주입과 깨끗한 설치 환경의 Hermes 실제 실행·빌드·독립 보안 검토입니다. 따라서 현재 시험 통과를 전체 정확성이나 공개 운영 준비의 완전한 증명으로 해석하면 안 됩니다.

## Hermes에서 사용

플러그인을 활성화한 뒤 새 Hermes 세션에서 실행합니다.

```text
/workflow start 이 저장소에 사용자 인증 기능을 추가한다
```

자세한 설치·사용·장애 대응 절차는 [사용 설명서](docs/user-guide.md)를 따릅니다.

## 설치

```bash
py -3.11 -m venv .venv
.venv/Scripts/python.exe -m pip install -e ".[dev]"
```

Hermes 데스크톱 환경에서는 전역 `PYTHONPATH`가 다른 설치본을 가리킬 수 있습니다. 현재 소스 트리를 검사할 때는 다음처럼 `PYTHONPATH`를 비우십시오.

```bash
PYTHONPATH='' \
  .venv/Scripts/python.exe -m pytest tests -q
```

## 종단 시연

```bash
PYTHONPATH='' \
  .venv/Scripts/python.exe -m agent_harness.cli demo \
  --root runs --json
```

시연은 낮은 위험의 비연구 과업을 대상으로 다음을 실제 파일과 SQLite 원장으로 수행합니다.

1. 목표 충분성 점검과 제작 경로 계획 수립
2. 다른 `mission_id` 결과 격리
3. 역할별 작업 공간에서 결과 수신
4. 결과 수신 시 인계 스키마와 산출물 해시 검산
5. 소스·요구 기준선·설계·빌드 설정·의존성을 포함한 후보본 동결과 재검산
6. 동결 후보본에서 실제 수락 검사를 실행하고 명령·종료 코드·출력·기대 결과·판정 규칙·관찰을 증거로 기록
7. 독립 검토자 승인
8. 출시 판정과 후보본·요구 기준선·도구 체인에 결속된 ZIP 생성

이 명령은 하네스 엔진의 작동을 확인하는 시연입니다. 수락 검사 한 건만 실행하므로 독립 코드 검토, 보안 검토, 연구 타당성 또는 전체 정확성의 증거로 사용하면 안 됩니다.

## 보안 범위

`WorkspaceBroker`는 하네스가 제공하는 파일 쓰기 경로에서 권한을 강제하고 기존 심볼릭 링크를 거부합니다. 임의의 외부 프로세스나 사용자가 운영체제 권한으로 파일을 직접 수정하거나 검사와 쓰기 사이에 경로를 바꾸는 것까지 막는 완전한 보안 경계는 아닙니다. 고위험 운영에서는 별도 Windows 계정, ACL, 컨테이너 또는 가상 머신을 함께 사용해야 합니다.

시험 통과는 구현된 시나리오에서 결함을 찾지 못했다는 뜻이며 모든 입력에서 완전한 정확성을 증명하지 않습니다.
